# Опис проєкту
**Task Manager** - це вебзастосунок для створення, організації та керування особистими завданнями. Він допомагає користувачам планувати свою діяльність, контролювати виконання завдань і відстежувати власний прогрес.
**Мета проєкту** - розробити зручний та зрозумілий інструмент для управління завданнями, який дозволить користувачам ефективніше організовувати свій час і повсякденні справи.

# Основний функціонал
- Створення нових завдань. 
- Перегляд списку завдань.
- Редагування та видалення завдань.
- Зміна статусу виконання завдань.
- Встановлення пріоритету завдань.
- Встановлення термінів виконання (дедлайнів).
- Пошук і фільтрація завдань.
- Реєстрація та авторизація користувачів.

# Цільова аудиторія
Люди, які хочуть організовувати свої повсякденні справи, навчальні завдання або робочі процеси за допомогою одного інструмента.
